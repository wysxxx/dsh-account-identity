# Demo assets

- `demo-avatar.png` is an original fictional cat illustration generated with OpenAI ImageGen for this project. It is a sample image for the avatar editor, not an interface screenshot.
- `crop.png` and `settings.png` are screenshots of the actual plugin running in the native Harness interface without a theme, with synthetic account data.
- `icon-180.png` is a deterministic raster export of the original project SVG icon.

These repository assets are covered by the project MIT license.
