# Changelog

## 0.2.0

- Added an avatar crop dialog with drag, zoom, keyboard movement and a live circular preview. The image is saved only after confirmation.
- Kept a square 128 × 128 PNG export and the native circular avatar presentation.
- Corrected switch sizing and explicitly preserved round corners under host and theme styles.
- Replaced the plugin icon with a compact blue and cyan identity card.
- Added crop resource, boundary and export regressions; retained reversible Claude Style name synchronization and theme-provided cost cards.

## 0.1.2

- Replaced the internal Harness Client Menu dependency with a plugin-owned menu mounted through public slots.
- Preserved custom names, avatars and Claude Style cost-card integration, including scoped keyboard and focus handling.
